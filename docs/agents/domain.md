# Domain documentation

This repository uses a single-context layout.

- Read the repository-root `CONTEXT.md`, if present, before making a material
  domain or architecture change.
- Read relevant decisions under `docs/adr/`, if present.
- Add or update `CONTEXT.md` when durable domain terminology or system context
  would otherwise be rediscovered repeatedly.
- Record consequential, durable architecture decisions as ADRs in `docs/adr/`.
