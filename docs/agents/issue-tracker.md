# Issue tracker

This repository tracks work in GitHub Issues at
[`fullmeta-dev/skills`](https://github.com/fullmeta-dev/skills/issues).

Use the `gh` CLI for issue operations. Create one issue for each independently
reviewable implementation slice. Record dependencies in each issue's
`## Blocked by` section, using GitHub issue references. Do not close or modify
parent issues unless the user explicitly requests it.

Pull requests are not part of the triage queue by default.
